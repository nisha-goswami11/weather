# Weather App

A simple realtime weather application built using HTML, CSS, and JavaScript.

## Features
- Search weather by city
- Realtime temperature
- Weather condition icons
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- Weather API
